# `swfr` Research & Specification Notes (`docs/notes/`)

This directory holds clean-room technical notes written in our own words (`docs/notes/<topic>.md`).

## Conventions (TSD 1.5)

1. Summarize binary record layouts, bit-packing rules, tag tables, and opcode semantics in your own words.
2. Every note must record its source URL and section number at the top of the file.
3. Code comments in `crates/*` should cite `docs/notes/<topic>.md` rather than copying verbatim specification text.
