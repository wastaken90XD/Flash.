## 1. `Value` Representation and `MovieClipReference` (`Confidence: High`)

- `Value<'gc>` (`core/src/avm1/value.rs:20-31`) is a 16-byte `Copy` enum (`assert!(size_of::<Value<'_>>() <= 16)`):
  - `Undefined`, `Null`, `Bool(bool)`, `Number(f64)`, `String(AvmString<'gc>)`, `Object(Object<'gc>)`, and `MovieClip(MovieClipReference<'gc>)`.
- **Why `Value::MovieClip` is Separate from `Value::Object` (`core/src/avm1/object_reference.rs:50-209`):**
  - In Flash Player AVM1, variables pointing to `MovieClip` display objects are **soft references** backed by their slash/dot target path (`_level0.foo.bar`) plus a fast-path weak reference (`cached_object: Lock<Option<ObjectWeak<'gc>>>`, `core/src/avm1/object_reference.rs:59-67`).
  - If the clip is still on stage (`!display_object.avm1_removed()`), `resolve_reference` returns the cached `Object` and `DisplayObject` in `O(1)` (`core/src/avm1/object_reference.rs:128-146`), even if `_name` was mutated after the reference was taken!
  - If the clip is removed (`avm1_removed()`), `resolve_reference` clears `cached_object` and walks the display tree from `_levelN` along `path_segments` (`core/src/avm1/object_reference.rs:150-183`). If a new clip is later attached/placed with the same name at that path, existing `Value::MovieClip` variables automatically resolve to the new clip!

## 2. Type Coercion by SWF Version (`Confidence: High`)

- **String Coercion (`Value::coerce_to_string`, `core/src/avm1/value.rs:307-352`):**
  - `Value::Undefined`: returns `""` (empty string) when `swf_version < 7`, and `"undefined"` when `swf_version >= 7` (`core/src/avm1/value.rs:312, 345`).
  - `Value::Bool(b)`: returns `"1"` / `"0"` when `swf_version < 5` (SWF 4), and `"true"` / `"false"` when `swf_version >= 5` (`core/src/avm1/value.rs:313-318, 347-348`).
  - `Value::Object(obj)`: returns the display object's `_target` path if it is a stage object, otherwise invokes `obj.call_method("toString", ...)` with `ExecutionReason::Special`, falling back to `"[type Function]"` or `"[type Object]"` (`core/src/avm1/value.rs:323-341`).
- **Boolean Coercion (`Value::as_bool`, `core/src/avm1/value.rs:354-369`):**
  - `Value::String(s)`: when `swf_version >= 7`, returns `!s.is_empty()` (ECMA-262 truthiness); when `swf_version <= 6`, parses `string_to_f64(s, swf_version)` and returns `!num.is_nan() && num != 0.0` (so `"0"` and `"hello"` are both `false` in SWF 6, while `"1"` is `true`!).
  - `Value::Object(_)` and `Value::MovieClip(_)` are always `true` (`core/src/avm1/value.rs:366`).
- **Primitive Coercion (`Value::to_primitive_num`, `core/src/avm1/value.rs:219-271`):**
  - Calls `valueOf()` with `ExecutionReason::Special`; for `Date` in SWF >= 6 without numeric hint, calls `toString()`.

## 3. Case Sensitivity by SWF Version (`Confidence: High`)

- **Cutover at SWF 7 (`Avm1::is_case_sensitive`, `core/src/avm1/runtime.rs:394-396`):**
  - `swf_version >= 7` is case-sensitive; `swf_version <= 6` is case-insensitive.
- **Dual Global Environments (`GlobalEnv`, `core/src/avm1/runtime.rs:28-68`):**
  - `Avm1` maintains **two** separate `GlobalEnv` instances: `env_case_sensitive` and `env_case_insensitive` (`core/src/avm1/runtime.rs:66-67`), and initializes `playerglobal` in both (`for swf_version in [6, 8]`, `core/src/avm1/runtime.rs:193-208`).
- **`PropertyMap<'gc, V>` (`core/src/avm1/property_map.rs:18-110`):**
  - Backed by `FnvIndexMap<PropertyName<'gc>, V>` where lookups wrap the key in either `CaseSensitive(&WStr)` or `CaseInsensitive(&WStr)` (`core/src/avm1/property_map.rs:25-75`).
  - Iteration (`PropertyMap::iter`, `core/src/avm1/property_map.rs:93-95`) reverses the `IndexMap` (`self.0.iter().rev()`) because Flash enumerates properties in **LIFO (most-recently-added-first)** order, and `remove` uses `shift_remove` to preserve insertion order (`core/src/avm1/property_map.rs:102-109`).

## 4. Scope Chain (`Global`, `Target`, `Local`, `With`) and `tellTarget` (`Confidence: High`)

- `Scope<'gc>` (`core/src/avm1/scope.rs:15-40`) is a GC-managed singly-linked list of `(parent: Option<Gc<Scope>>, class: ScopeClass, values: Object)`:
  - `ScopeClass::Global` — root `_global` object (`core/src/avm1/scope.rs:17`).
  - `ScopeClass::Target` — timeline scope pointing to a `MovieClip`'s script object (`core/src/avm1/scope.rs:22`).
  - `ScopeClass::Local` — function activation local variables, inherited by closures in SWF 6+ (`core/src/avm1/scope.rs:25`).
  - `ScopeClass::With` — pushed by `ActionWith (0x94)`, **not** inherited when a nested closure is defined (`core/src/avm1/scope.rs:29`).
- **Closure vs Non-Closure Scope (`Avm1Function::exec`, `core/src/avm1/function.rs:297-335`):**
  - In **SWF 6+** (`activation.swf_version() >= 6`), functions are true lexical closures: they use `self.swf_version()`, `self.base_clip`, and close over `self.scope()`.
  - In **SWF 5**, functions are **not** closures: they use the `swf_version` and `base_clip` of `this` and allocate a fresh `ScopeClass::Target` over `this` without closing over the defining function's `Local` scope (`core/src/avm1/function.rs:318-334`)!
- **`tellTarget` (`ActionSetTarget` `0x8B` and `ActionSetTarget2` `0x20`, `core/src/avm1/activation.rs:2056-2089`, `Scope::new_target_scope`, `core/src/avm1/scope.rs:63-77`):**
  - Clones the current scope chain and replaces the `ScopeClass::Target` node's `values` object with the new target clip's object (`core/src/avm1/scope.rs:70-74`).
  - If `SetTarget` is given an invalid/missing path, the target clip becomes `None` and variable lookups fall back to `_root` (`tests/tests/swfs/avm1/tell_target/output.txt:4-6`).
  - If `SetTarget("")` or `SetTarget2(undefined)` (in SWF <= 6) is called, the target resets to `self.base_clip()` (`core/src/avm1/activation.rs:2071-2078`).

## 5. `DefineFunction` vs `DefineFunction2` and Register Preloads (`Confidence: High`)

- **Global vs Local Registers (`core/src/avm1/runtime.rs:77`, `core/src/avm1/function.rs:360-400`):**
  - `DefineFunction` (`0x9B`) has `register_count == 0`, so `local_registers` is empty (`&[]`, `core/src/avm1/activation.rs:205`) and `Push(Register(i))` / `StoreRegister(i)` access the 4 shared global registers `Avm1.registers: [Value<'gc>; 4]` (`core/src/avm1/runtime.rs:77`).
  - `DefineFunction2` (`0x8E`) allocates `self.register_count()` local `Cell<Value<'gc>>` slots (`core/src/avm1/function.rs:360-362`).
  - **Preload Order (`core/src/avm1/function.rs:377-385`):** Starting at **`preload_r = 1`** (local register `0` is never preloaded by flags!), `DefineFunction2` checks `FunctionFlags` in exact bit order:
    1. `PRELOAD_THIS` (`load_this`, `core/src/avm1/function.rs:379`)
    2. `PRELOAD_ARGUMENTS` (`load_arguments`, `core/src/avm1/function.rs:380`)
    3. `PRELOAD_SUPER` (`load_super`, `core/src/avm1/function.rs:381`)
    4. `PRELOAD_ROOT` (`load_root`, `core/src/avm1/function.rs:382`)
    5. `PRELOAD_parent` (`load_parent`, `core/src/avm1/function.rs:383`)
    6. `PRELOAD_GLOBAL` (`load_global`, `core/src/avm1/function.rs:384`)
  - Then parameters with `param.register = Some(reg)` overwrite `local_registers[reg]`, while parameters with `param.register = None` are defined in the local scope via `force_define_local` (with missing trailing arguments explicitly set to `Value::Undefined` so assignments to unassigned parameter names do not leak to outer scopes; `core/src/avm1/function.rs:386-400`).

## 6. Prototype Chain, `__proto__`, `super`, and `Object.registerClass` (`Confidence: High`)

- **`SuperObject<'gc>` (`core/src/avm1/object/super_object.rs:1-137`):**
  - Tracks `(this: Object<'gc>, depth: u8)` (`core/src/avm1/object/super_object.rs:22-26`).
  - `base_proto` walks `this`'s `__proto__` chain `depth` steps (`core/src/avm1/object/super_object.rs:58-68`).
  - Calling `super(args)` looks up `__constructor__` on `base_proto` and runs it with `depth + 1` (`core/src/avm1/object/super_object.rs:77-106`); calling `super.method(args)` searches the prototype chain starting at `base_proto.proto()` and invokes `method` with `self.depth() + depth + 1` (`core/src/avm1/object/super_object.rs:108-136`) so multi-level `super.foo()` chains do not infinite-loop!
- **`Object.registerClass(symbolName, theClass)` (`core/src/avm1/runtime.rs:569-634`, `core/src/player.rs:2223-2252`):**
  - Stores `(symbol -> constructor)` in `GlobalEnv.constructor_registry` (`core/src/avm1/runtime.rs:40, 610-634`).
  - When a `MovieClip` with that exported symbol is placed or attached, it queues `ActionType::Construct { constructor: Some(constructor), events }` in `ActionPriority::Construct`, which sets `clip.__proto__ = constructor.prototype`, runs `onClipEvent(construct)` bytecode, and calls `constructor.construct_on_existing(&mut activation, object, &[])` (`core/src/player.rs:2233-2251`).

## 8. Recursion and Instruction Limits (`Confidence: High`)

- **Three Separate Recursion Limits (`ActivationIdentifier::function`, `core/src/avm1/activation.rs:107-144`):**
  1. `max_recursion_depth: u16` (defaults to **`255`**, configurable via `ScriptLimits` tag; `core/src/avm1/runtime.rs:128`, `core/src/avm1/activation.rs:132-134`).
  2. `PROPERTY_RECURSION_LIMIT: u16 = 65` per `property_id` for getter/setter/`watch` recursion (`core/src/avm1/activation.rs:118-121`).
  3. `special_count == 65` for `ExecutionReason::Special` (`toString` / `valueOf` recursion; `core/src/avm1/activation.rs:124-128`).
- **Instruction Timeout (`max_execution_duration`, `core/src/player.rs:2540`):** Checked inside the bytecode loop; if exceeded or if `FunctionRecursionLimit` is hit, `Avm1::handle_error` calls `context.avm1.halt()` (`core/src/avm1/runtime.rs:688-693`), whereas `Error::ThrownValue` logs `"Uncaught exception, ..."` and continues without halting (`core/src/avm1/runtime.rs:667-684`).

## 13. Test Ideas for `swfr`

1. **SWF 6 vs SWF 7 case-insensitivity & boolean-string test:** Test that in SWF 6, `if ("0")` is false and `myVar` / `MYVAR` alias the same variable, whereas in SWF 7, `if ("0")` is true and `myVar` / `MYVAR` are distinct.
2. **3-level `Extends` + `super()` constructor chain test:** Create `A`, `B extends A`, `C extends B` where each constructor calls `super()` and traces its class name, verifying `A -> B -> C` without infinite recursion.
3. **`tellTarget` invalid/undefined recovery test:** Model a test on `tests/tests/swfs/avm1/tell_target` verifying `SetTarget("INVALID")` resolves variables on `_root` and `SetTarget("")` / `SetTarget2(undefined)` restores `base_clip`.
