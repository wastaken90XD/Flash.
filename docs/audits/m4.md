## 2. Issues Found & Fixed During TSD 3.14 Re-Audit

1. **`aarch64-apple-darwin` variadic `retro_log_printf_t` calling convention (`crates/swfr-libretro/src/ffi.rs`):**
   - On `aarch64-apple-darwin` (Apple Silicon ABI), variadic arguments (`...`) are passed on the stack rather than registers. Passing `%s\n` as `fmt` and the message pointer as a variadic argument caused non-variadic Rust test log callbacks to read an invalid pointer on macOS ARM64. Fixed `emit_log` in `crates/swfr-libretro/src/ffi.rs` to escape `%` as `%%` and pass the formatted log line directly as the fixed `fmt` parameter (`log_fn(level, c_str.as_ptr())`), verified on `ubuntu-latest`, `macos-latest` (`aarch64-apple-darwin`), `windows-latest`, and QEMU `armv7-unknown-linux-gnueabihf` in `e2e_as2_trace_hello_delivers_log_callback`.
