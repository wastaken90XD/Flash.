## 2. Issues Found & Fixed During TSD 3.14 Re-Audit

1. **`DefineShape4` (`LINESTYLE2`) parsing in real SWF files (`crates/swfr-swf/src/lib.rs`):**
   - `decode_line_style_array` previously read the 16-bit `LINESTYLE2` flags with `r.u16()?` (little-endian) instead of MSB-first bit fields (`StartCapStyle UB[2]`, `JoinStyle UB[2]`, `HasFillFlag UB[1]`, ..., `EndCapStyle UB[2]`) and called `decode_fill_style_array` (which reads a count byte) instead of `decode_single_fill_style` when `HasFillFlag == 1`. Fixed and verified against `corpus/real/MANIFEST.toml` in `e2e_real_corpus_manifest_runs_120_frames_without_m0_stub`.
2. **`DefineMorphShape` non-solid fill styles (`crates/swfr-swf/src/lib.rs`):**
   - `decode_morph_shape` previously ignored gradient stops and bitmap IDs on non-solid morph fill styles (`0x10`, `0x12`, `0x13`, `0x40..=0x43`). Fixed to consume morph gradient records (`NumGradients`, start/end ratio + RGBA pairs) and morph bitmap matrices.
